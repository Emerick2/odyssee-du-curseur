# odyssee-du-curseur
L’Odyssée du Curseur est un jeu de déplacement à la souris dans un environnement spatial.


Liste des données de sauvegardes concerver :
- niveauActuel+"_pieces"
- niveauActuel+"_score"
- niveauActuel+"_temps"
- niveauActuel+"_tentative"

# Lancer le serveur :
- `python -m http.server 8080 --bind 0.0.0.0`
- Aller sur : http://localhost:8080/scenes/menu.html
